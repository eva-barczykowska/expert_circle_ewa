# **App Name**: Ewa Expert Circle

## Core Features:

- Question Display: Display the main question: 'Accept Ewa to the Expert Circle?' along with Yes/No buttons.
- Button Logic: Implement 'Yes' button functionality to display a thank you message. Implement 'No' button to escape cursor to prevent selection.
- Confirmation Message: Show a thank you message when the 'Yes' button is clicked.

## Style Guidelines:

- Primary color: White or light grey for the background.
- Button colors: Magenta for the 'Yes' button, grey for the 'No' button.
- Accent: A brighter shade of magenta for button hover/focus states.
- Simple, centered layout for the question and buttons.
- Subtle animations on button hover/click for user feedback.
